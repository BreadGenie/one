# Frappe One

A home repo for working across the Frappe ecosystem. Start here when a change
spans Frappe Framework and its apps, from ERPNext and CRM to Suite and Raven.

- [Repository map](AGENTS.md) lists the product checkouts, upstream repositories,
  and where to find each repo’s instructions.
- [Local development with Pilot](docs/pilot-setup.md) covers testing from an app
  worktree and running multiple apps together on `develop`.

Open this repo in your coding agent, then make and test changes in the relevant
product checkout.
